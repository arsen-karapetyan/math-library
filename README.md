# Մաթեմատիկայի թվային գրադարան

Ստատիկ կայք (HTML, CSS, JavaScript)՝ առանց սերվերի և կառուցման գործիքների։ Աշխատում է GitHub Pages-ում։

## Ինչպես հրապարակել GitHub Pages-ում

1. Մտեք [github.com](https://github.com), սեղմեք **New repository**, տվեք անուն (օրինակ՝ `math-library`), ընտրեք **Public** և ստեղծեք։
2. Բացեք նոր repository-ն և սեղմեք **Add file → Upload files**։
3. Քաշեք այս պանակի **ամբողջ պարունակությունը** (`index.html`, `style.css`, `script.js`, `fonts/`, `data/`, `pdfs/`)։ Կարևոր է, որ `index.html`-ը լինի repository-ի արմատում, ոչ թե ներքին պանակում։ Սեղմեք **Commit changes**։
4. Գնացեք **Settings → Pages**։
5. **Build and deployment → Source** դաշտում ընտրեք **Deploy from a branch**։ **Branch**-ի համար ընտրեք `main` և `/ (root)`, ապա սեղմեք **Save**։
6. Սպասեք 1–2 րոպե. էջի վերևում կհայտնվի հասցեն՝ `https://<ձեր-անունը>.github.io/math-library/`։

Եթե PDF-երը բեռնելիս բրաուզերը սահմանափակում է ֆայլերի քանակը, ֆայլերը կարող եք վերբեռնել մի քանի մասով։

## Նոր PDF ավելացնելը

1. Ֆայլը անվանեք **`dd.mm.yyyy - Ազգանուն.pdf`** օրինակով, որտեղ ազգանունը կամ `Դավիդովա` է (դասախոսություն), կամ `Բարխուդարյան` (սեմինար)։
2. Դրեք այն `pdfs/` պանակում։
3. `data/documents.js` ֆայլում ավելացրեք մեկ գրառում՝ `file` (ճիշտ նույն անունը), `pages`, `topics` և `description` դաշտերով։ Ամսաթիվը, դասախոսը և կատեգորիան կայքը վերցնում է ֆայլի անունից։

## Կարևոր նշումներ

- GitHub Pages-ը տարբերում է մեծ և փոքր տառերը ֆայլի անվան մեջ. `data/documents.js`-ի `file` արժեքը պետք է համընկնի իրական անվանը նույնությամբ (օրինակ՝ `.PDF` և `.pdf` տարբեր են)։
- `04.11.26 - Դավիդովա.PDF` ֆայլի անվան մեջ տարին երկնիշ է. կայքը այն ցույց է տալիս որպես 04.11.2026, իսկ ֆայլի անունը անփոփոխ է։
- Տեղական դիտման համար բացեք `index.html`-ը բրաուզերում։ Առանձին սերվեր պետք չէ։
